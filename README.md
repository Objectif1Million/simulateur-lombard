# Simulateur Lombard — Objectif 1 Million

Simulateur interactif qui compare 4 stratégies de gestion de patrimoine :
- **Lombard** : salaire 100% investi, dépenses financées par crédit
- **Classique** : surplus investi après dépenses
- **Vendre pour vivre** : vente d'actifs pour couvrir les dépenses
- **Hold only** : portefeuille existant sans ajout

Tous les montants en CHF réels, corrigés de l'inflation.

## Stack
- React 18
- Recharts
- Vite

## Déploiement sur Vercel
1. Push ce repo sur GitHub
2. Connecte-le à Vercel
